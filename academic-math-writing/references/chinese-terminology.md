# 中文数学术语

本词表适用于中文数学写作和英译中。按词语在命题中的数学含义选用译法。引文、书目题名与数值验证出处按原有写法保留。

| 英文 | 译法 | 适用语境 |
| --- | --- | --- |
| sharp | 最优、最佳 | 禁用“尖锐”。指出最优的是常数、指数、取值范围、误差阶或其他具体量。例如“最优常数”，并说明可达性或不可改进性在文中的准确含义。 |
| real | 实数的、实的，或合成词中的“实” | 指实数域、实值或实结构时，禁用“真实”。如“实系数”“实值函数”。 |
| complex | 复数的、复的，或合成词中的“复” | 指复数域、复值或复结构时，禁用“复杂”。如“复向量空间”。作为另一个数学名词时遵循该概念的专门译名，如 chain complex 为“链复形”。 |
| 与 super- 成对的 sub- 名词 | 次-、下- | 按该领域的命名习惯选择并保持成对一致。subsolution 用“次解”或“下解”，禁用“子解”。黏性解语境用“下解／上解”。subgroup、subspace 等沿用“子群”“子空间”。 |
| apply | 代入 | 写明代入对象及其进入的式子、定义或命题条件。援引定理时，可把句子重写为“由定理 X 的……条件，得……”，以交代实际推理。 |
| hold | 成立 | 写明成立的命题、等式或不等式及其范围。如“对每个 \(x\in D\)，式 (2) 成立”。 |
| support in / supported in | 首选 \(\operatorname{supp} f\subset E\)，或写“\(f\) 的支集包含在 \(E\) 中” | 表达函数、测度或分布的支集包含关系时，采用公式或以“支集”为名词的句式。将 \(f\) 和 \(E\) 换成原文对应的对象与集合。 |

## 补充词条

在表末追加一行，填写英文术语、指定译法和适用语境。若需限定数学分支、列出禁用译法或给出成对术语，在第三列注明。相同词语在不同概念中有不同译法时分行记录，并用适用语境区分。
